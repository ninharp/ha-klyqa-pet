# Brand assets

The files under `klyqa_pet/` in this directory are prepared for submission as a
pull request to [home-assistant/brands](https://github.com/home-assistant/brands),
under `custom_integrations/klyqa_pet/`.

Home Assistant loads integration icons and logos from `brands.home-assistant.io`,
which is built from that repository. The `klyqa_pet` icon will therefore only
appear in the Home Assistant UI once the brands PR has been submitted and merged;
until then, the integration falls back to a generic icon.

The source image is the Klyqa wordmark as used on klyqa.de. It is a 260x60 PNG
raster, so the generated assets are only as sharp as that source; a vector or
higher-resolution source (e.g. an official SVG logo from Klyqa) would improve
the quality of the icon and logo files before submitting the PR.
